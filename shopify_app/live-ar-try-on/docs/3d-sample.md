# Supplied 3D sample

Original: user-provided `white_mesh.glb`, copied to `models/white-mesh.glb` without modification. GLB 2.0, generated by trimesh, 684,792 bytes; 16,992 vertices and 40,000 triangles. One mesh, no skeleton/skins, animations, textures, UVs, normals or authored materials.

`node scripts/prepare-model.mjs` produces equivalent self-contained glTF JSON in `extensions/live-ar/assets/white-mesh.gltf.json`. It preserves the binary geometry exactly, embedding the buffer as a data URI. JSON is used because GLB is not a supported theme-extension asset format. The original GLB is preserved for later rigging/texturing.

The fourth demo selection, **3D white mesh (experimental)**, lazy-loads Three.js only after camera permission. It uses generated vertex normals and a plain white lit material. The adaptive pilot now deforms its torso and sleeves using sample-specific landmarks, with visual width/length adjustments. It does not simulate cloth, replace underlying clothing or solve body occlusion. Normal 2D sample alignment remains available. See [adaptive-preview.md](adaptive-preview.md) for limitations and the next asset requirements.

Run `npm run demo:ar` and open `/model-check` for a camera-free front/side inspection with a rotation slider, or open `/` and select the fourth garment for the camera experiment. HTTPS Shopify preview can use the same fourth sample after updating the development extension. This sample is not mapped to a real product and cannot be purchased. No production deployment is included.

Next asset requirements for realistic movement: UVs and texture maps; a clean, appropriately scaled garment mesh; an armature and skin weights for shoulders/elbows; garment anchor calibration. Camera performance and alignment still require physical-device testing.

Validation: 27 tests passed, including byte-for-byte equivalence of the GLB geometry buffer and packaged glTF; build, typechecking and Shopify Liquid validation passed. Browser verified front and 90-degree side rendering with the real GPU renderer, and the fourth sample selection in the camera dialog. No camera permission was accepted in these checks. Extension total is approximately 9.08 MB, below the 10 MB build limit.
